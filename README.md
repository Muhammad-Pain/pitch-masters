# Pitch Masters 3.0 — 3D-футбол на C++ (Godot 4.6 + GDExtension)

Весь код игры написан на C++: матч, ИИ, физика мяча, меню, карточки, лига, патчи и PvP.
Godot используется только как движок: рисует 3D, звук и собирает APK.
Клубы, игроки и бренд выдуманные.

## Скачать APK

Каждый пуш в `main` автоматически собирает APK через GitHub Actions.
Готовый файл — во вкладке **Releases** (последняя «сборка N») или в **Actions → Build APK → Artifacts**.

Чтобы новые сборки ставились поверх старых без удаления, добавьте в **Settings → Secrets and variables → Actions** три секрета:
`ANDROID_KEYSTORE_BASE64` (keystore в base64), `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`.
Без них каждая сборка подписывается временным ключом — перед установкой удалите прошлую версию.

## Что нового в 3.0

- **Настоящие 3D-футболисты** вместо капсул: скелет, анимации бега, рывка, удара, прыжка вратаря и празднования, форма клуба (полосы, обручи, половинки), номера на спине, разный цвет кожи и волос.
- **Графика матча**: тени от солнца, трава с полосами покоса и износом у ворот, болельщики в цветах команд, свечение и тонмаппинг, камера ближе к игре.
- **Повтор гола** в замедлении с кинокамерой (можно пропустить касанием или выключить в настройках).
- **Оценки игроков и лучший игрок матча**, статистика передач, ударов и владения.
- **Прокачка карточек**: игроки получают опыт за оценку в матче и растут до 10-го уровня (+1 ко всем характеристикам за уровень).
- **Ежедневная награда** с серией входов (7-й день — большой приз) и **3 задания дня**.
- **Новое меню**: 3D-игрок вашего клуба на главном экране, нижняя навигация (Главная, Играть, Клуб, Магазин, Ещё), стеклянные карточки, анимации.
- **Современный HUD**: компактное табло, полоса выносливости и силы удара под игроком, новые кнопки.

## Как собрать APK (Windows)

1. Установите:
   - [Godot 4.6](https://godotengine.org/download) (обычная версия, не .NET);
   - [Android Studio](https://developer.android.com/studio). В SDK Manager → SDK Tools отметьте «Show Package Details» и поставьте **NDK 28.1.13356709**, а также **Android SDK Build-Tools**.
     Другая версия NDK тоже подойдёт: перед сборкой выполните `set NDK_VERSION=ваша_версия`;
   - [Python 3](https://www.python.org/downloads/) (при установке отметьте «Add to PATH») и [Git](https://git-scm.com/).
2. Откройте командную строку в папке проекта и выполните:
   ```
   set ANDROID_HOME=C:\Users\ВАШЕ_ИМЯ\AppData\Local\Android\Sdk
   build_android.bat
   ```
   Скрипт скачает godot-cpp и соберёт библиотеку игры для телефонов (arm64 и arm32) и для Windows (`game\bin\`).
3. В Godot: **Import → папка `game`**. Затем **Editor → Manage Export Templates → Download**,
   в **Editor Settings → Export → Android** укажите Android SDK.
4. **Project → Export → Android → Export Project** — получите `PitchMasters.apk`.

На Linux/macOS вместо `.bat` запустите `./build_android.sh`.

Проверить игру на ПК: после шага 2 откройте папку `game` в Godot и нажмите F5.
Клавиатура: WASD — бег, J — пас, L — пас на ход или прессинг, I — навес, K — удар (держать), Shift — рывок, P — пауза.

## Патчи

Файл патча — это `.pmpatch` (обычный zip) или `.json`. Внутри архива:

```
patch.json
logos/club_1.png     ← эмблемы, PNG примерно 128×128
images/menu.png      ← необязательно: фон главного меню
```

Пример `patch.json`:

```json
{
  "name": "Сезон 2027",
  "author": "Ваше имя",
  "version": "1.0",
  "league_name": "Премьер-лига 2027",
  "boards": ["СЕЗОН 2027", "ГОЛ!"],
  "menu_background": "images/menu.png",
  "my_team": {"name": "ФК Душанбе", "short": "ДУШ", "shirt": "#0b3d91", "shorts": "#ffffff", "logo": "logos/me.png"},
  "teams": [
    {"name": "Памир Юнайтед", "short": "ПАМ", "shirt": "#1f4fd1", "shorts": "#ffffff", "strength": 82,
     "logo": "logos/club_1.png",
     "players": [{"name": "Тимур Сафаров", "pos": "CF", "ovr": 84, "num": 9}]}
  ]
}
```

- `strength` — сила клуба от 40 до 95.
- `players` — необязательно. Позиции: GK CB LB RB DMF CMF AMF LMF RMF LWF RWF CF.
  Параметры `pace sho pas dri def phy gk` тоже необязательны: без них они считаются от `ovr`.
- Если клубов меньше семи, лига добирает стандартные.

В игре есть кнопки **«Установить пример „Сезон 2027“»** (готовый патч с эмблемами) и **«Шаблон для своего патча»**:
вторая сохраняет заготовку `PitchMasters_patch_template.json` в папку «Загрузки».

На Android файл выбирается через системное окно выбора файлов. Положите патч в «Загрузки» и нажмите «Добавить файл патча».

## Структура кода

```
src/game_data.*      карточки, состав, лига, сохранения, награды
src/patch.cpp        установка, проверка и включение патчей, шаблон, пример с эмблемами
src/app.*            менеджер экранов и 3D-стадион за меню
src/ui_kit.*         кнопки, панели, карточки игроков, модальные окна
src/screen_*.cpp     заставка, меню, состав, паки, лига, PvP-лобби, настройки, патчи, итоги
src/match/match.*    правила, физика мяча, ИИ, вратари, управление, синхронизация PvP
src/match/hud.*      табло с эмблемами, радар, мультитач-джойстик и кнопки
src/match/stadium.*  поле, ворота, щиты, трибуны, свет
src/match/footballer.* модель игрока и анимация бега
src/net.*            PvP по Wi-Fi (ENet), кнопка «АВТО» для каждого игрока
src/sfx.*            процедурные звуки
game/                проект Godot (сцена, настройки, пресет экспорта Android, тесты)
```

Автотесты (запускаются без экрана):
`godot --headless --path game --fixed-fps 60 res://tests/sim.tscn -- 3` — матчи ИИ против ИИ;
`ui.tscn` — все экраны и матч со случайным управлением; `patch.tscn` — установка и включение патчей.

## Чего пока нет

Офсайдов, фолов, пенальти и замен по ходу матча. PvP работает только по локальной сети.
